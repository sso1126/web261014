## 어려웠던 점 3가지와 해결
1. 박스 모델 구성하기
HTML 요소들의 크기와 여백을 조절하여 전체적인 레이아웃을 구성하는 것이 어려웠다. 특히 margin, padding, border의 차이를 이해하고 각 요소에 적절하게 적용하는 과정에서 헷갈리는 부분이 있었다. 각 속성이 요소의 배치와 크기에 어떤 영향을 주는지 익숙하지 않았기 때문이다.
2. CSS를 활용하여 디자인 적용하기
영화 보드의 배경, 글자 색상, 간격, 정렬 등을 CSS로 꾸미는 과정이 어려웠다. 원하는 디자인을 만들기 위해 여러 CSS 속성을 함께 사용해야 했고, 속성에 따라 화면이 어떻게 달라지는지 파악하는 데 시간이 걸렸다. CSS의 다양한 속성과 선택자의 사용법이 아직 익숙하지 않았기 때문이다.
3. 반응형 웹 구현하기
화면 크기에 따라 영화 카드의 배치와 개수가 달라지도록 미디어 쿼리를 작성하는 것이 어려웠다. 특히 화면 너비에 따라 1열, 2열, 4열로 변경되도록 설정하고, 작은 화면에서도 가로 스크롤 없이 콘텐츠가 잘 보이도록 조정하는 과정이 헷갈렸다. 미디어 쿼리의 적용 기준과 각 CSS 속성이 레이아웃에 미치는 영향을 충분히 이해하지 못했기 때문이다. 이번 과제를 통해 HTML로 웹페이지의 구조를 만들고 CSS로 디자인을 적용하는 과정을 경험할 수 있었다. 아직 헷갈리는 부분도 있지만, 직접 문제를 해결하면서 HTML과 CSS의 기본 개념을 더 잘 이해할 수 있었고, 앞으로는 다양한 CSS 속성을 연습하여 원하는 웹페이지를 더 정확하게 구현하고 싶다.

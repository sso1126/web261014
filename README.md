## 구현 항목 체크
- [O] 1. CSS 변수: style.css 맨 위 :root에 색 5개 이상, 글꼴 2개(구글 폰트), 간격 1개. 글자색, 배경색, 테두리색은 모두 var()로 씁니다(그림자와 오버레이의 반투명 검정 rgba(0, 0, 0, ...)은 예외).
- [O] 2. 섹션 2개: <section id="mine"> 내 인생 영화 5편, <section id="boxoffice"> 일별 박스오피스 TOP 5(기준일 표시). 섹션마다 <h2>, 카드 제목은 <h3>.
- [O] 3. 카드 10장의 포스터: TMDB 포스터 w342, alt에 "제목 포스터". 포스터가 없는 영화는 대체 표지.
- [O] 4. 박스오피스 배지: 순위 배지 .rank(왼쪽 위), 누적 관객 수(천 단위 콤마, "명"), 순위 변동 .up, .down, .new(::before로 ▲, ▼, NEW와 색).
- [O] 5. 6주차 효과 유지: 평점 배지 .badge(오른쪽 위), :hover에서 0.3초 동안 8px 떠오르고 노란빛 그림자가 생김.
- [O] 6. 보드 격자: display: grid, 폭 360px 1열, 768px 2열, 1280px 4열. 미디어 쿼리 2개(min-width: 600px, minwidth: 1024px)가 각각 눈에 보이는 변화를 만듦. 360px에서 가로 스크롤 없음.
- [O] 7. 헤더: flex로 제목 왼쪽, 내비 오른쪽. 내비 링크 3개(#mine, #boxoffice, detail.html). 본문 max-width: 1100px 가운데 정렬.
- [O] 8. 히어로: backdrop_path의 w1280 배경 + 어두운 그라데이션 오버레이, 제목과 한 줄 소개.
- [O] 9. 상세 페이지 detail.html: 내 인생 영화 1편. 600px 이상에서 2단 grid(왼쪽 포스터 w500, 오른쪽 <dl>에 제목, 원제, 개봉일, 평점, 줄거리 전문), 배경에 backdrop_path 오버레이, "보드로 돌아가기" 링크, 헤더와 푸터는 index.html과 같음.
